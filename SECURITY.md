# Security Policy

Please do not publish credentials, OAuth files, request bodies, production logs, IP addresses, or private deployment details in issues or pull requests.

For a suspected vulnerability, contact the maintainers privately with a minimal reproduction and the affected commit. Rotate exposed keys immediately, then remove them from every reachable Git history before making the repository public.

This project is a deployment template. Operators are responsible for TLS, firewall rules, OS updates, Docker permissions, account-provider terms, and access control on the host.
